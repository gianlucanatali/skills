# Contextual Naming

Generate five names by default, or the number requested. Infer purpose, audience,
tone, and language from the current conversation; ask only if essential context
is missing. Favor names people can pronounce, spell, and remember. Do not expose
private project details in search queries; search candidate names and generic categories.

## Generate and screen

1. Generate more candidates than needed using these strategies:
   - **Neologism:** combine distant linguistic roots or invent pronounceable phonemes.
   - **Portmanteau:** blend relevant words, shortening or changing the join.
   - **Phonetic Alteration:** reshape a generic concept word. Never respell a brand
     to evade a conflict; similar sounds can still conflict.
2. Discard recognized brands, famous names, and confusingly similar spellings or
   sounds, including tech, pharma, fashion, and entertainment names. An unfamiliar
   spelling or an internal intuition is not evidence of availability.
3. When browsing is available, search each surviving name individually in quotes,
   then check plausible spaced, hyphenated, and phonetic variants for related uses.
   For software, also check GitHub and relevant package registries. Check domains
   only when requested; domain availability does not establish trademark clearance.
4. When trademark screening is requested, check relevant official registers (for
   example USPTO, EUIPO/TMview, or WIPO), including similar names in relevant goods
   and services. State the jurisdictions and search scope. If register access fails
   or only indexed web results are available, disclose that limitation explicitly.
5. Replace candidates with clear existing uses or plausible confusing conflicts.
   Stop after three screening rounds if too few remain; return the verified subset
   and explain the shortfall instead of padding with unchecked names. If browsing
   is unavailable or prohibited, label all suggestions **unscreened**.

## Output

Lead with your favorite and a short reason. For each option use:

- **[Name]**
  - **Type:** Neologism, Portmanteau, or Phonetic Alteration.
  - **Why it works:** One short connection to the project's purpose.
  - **Originality check:** What was actually checked and found, with source links
    where available; distinguish unsearched, inconclusive, and no conflict found.

Share the search date and common scope once to avoid repetition. Never fabricate
sources or treat zero results as proof of uniqueness. Do not call names legally
safe, copyright-free, trademark-free, or guaranteed available. An invented blend
is a generation method, not a legal conclusion. Keep the qualification brief:
preliminary screening is not legal trademark clearance.

Naming alone does not authorize registering domains, reserving accounts, creating
repositories, or filing trademarks. Continue those actions only if separately
authorized by the user.
